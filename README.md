## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **SSH & Telnet Support** — Connect securely to remote servers using SSH and Telnet protocols.
- **User-Friendly Interface** — Easy to navigate for both beginners and advanced users.
- **Versatile Protocols** — Support for SCP, SFTP, and TCP raw protocols for comprehensive server communication.
- **Port Forwarding** — Utilize SSH port forwarding to secure your connections.
- **Flexible Terminal Emulators** — Compatible with VT102, ECMA-48, and xterm terminal emulators for diverse terminal experiences.

### Advanced Features:
- **IPv6 Support** — Ensures connectivity with modern network configurations.
- **Strong Encryption** — Supports multiple encryption algorithms including AES, 3DES, and Blowfish for secure connections.
- **Continuous Development** — Regular updates keep the software optimized and secure.
